# Interview Question Generator

This repository contains code for analyzing a dataset containing software engineering questions. 

# Data Preprocessing
1. Downloads and Loads dataset
  -Loads the data set into pandas framwork

2. Text cleaning
  -Converts text to lowercase
  -Removes puncitation
  -Removes stop words
  -Lemmatizes words

3. Named Entity Recognition (NER):
  -Extracts named entities from text using spaCy

4. Sentiment Analysis:
  -Perform sentiment analysis on text using TextBlob

5. TF-IDF Vectorization
  -Converts cleaned text into TF-DF matrix

6. Save cleaned data
  -Save cleaned data to CSV file
